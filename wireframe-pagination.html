2 — Pagination component: all states Task 2.4 — src/components/ui/Pagination.tsx

State A — First page (Prev disabled)

← Prev is opacity-40 cursor-not-allowed

State B — Middle page (ellipsis both sides)

Always show: first, last, current±1. Insert … for gaps.

State C — Last page (Next disabled)

→ Next is opacity-40 cursor-not-allowed

State D — Few pages (≤ 7, no ellipsis)

When last_page ≤ 7, show all page numbers — no ellipsis needed.

Component design decisions

  • Props: meta: PaginationMeta, onPageChange: (page: number) => void
  • Active page: bg-indigo-500 border-indigo-500 text-white font-bold
  • Inactive: bg-white border-gray-200 text-gray-700 hover:bg-gray-50
  • Disabled: opacity-40 cursor-not-allowed pointer-events-none
  • Desktop/mobile split: hidden md:flex for desktop pills, flex md:hidden for mobile compact
  • Ellipsis page window algorithm: show [1, …, current−1, current, current+1, …, last] clamped at boundaries
  • Returns null when meta.last_page <= 1 (no bar needed)

Frontend types to add (types.ts) — Task 2.2

interface PaginationMeta {
  current_page: number;
  last_page:    number;
  per_page:     number;
  total:        number;
}

interface PaginatedResponse<T> {
  data: T[];
  meta: PaginationMeta;
}
